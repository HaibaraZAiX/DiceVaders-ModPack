# 使用说明

## 这是什么

《DiceVaders》的几个体验优化 Mod：
- 商店概率显示
- 无限时空点 / 挪移
- 星座可刷新
- 开局专长三选一（前两个是指挥官专属专长）
- 游戏原生设置面板里多出开关行
- 难度机制解除

---

## 怎么装

1. 打开 Steam → 库 → 右键 **DiceVaders** → 管理 → **浏览本地文件**
   （会打开游戏的安装目录，里面应该能看到 `DiceVaders.exe`）

2. 把本压缩包里的这些**全部解压到那个目录**（提示覆盖就选「全部覆盖」）：

   ```
   BepInEx\
   dotnet\
   winhttp.dll
   doorstop_config.ini
   .doorstop_version
   ```

3. 启动游戏。**第一次启动会慢一些**（要生成 Il2CppInterop 的桥接程序集，大约 1~3 分钟），之后启动就快了。

4. 进游戏 → 设置界面 → 应该能看到多出来的几行「★ Mod：…」开关。

---

## 怎么确认装上了

游戏根目录下会出现 `BepInEx\LogOutput.log`。启动一次后打开它，搜 `DiceVaders`，应该能看到：

```
Loading [DiceVaders ShopInfo 1.0.0]
Loading [DiceVaders Infinite Resources 2.0.0]
Loading [DiceVaders Constellation Tool 3.1.0]
Loading [DiceVaders Native Sandbox Rows 1.0.0]
Loading [DiceVaders Extra Reward Option 1.3.0]
Loading [DiceVaders QoL 1.0.0]
```

## 各项功能怎么用

### 商店概率显示
进商店就能看到界面旁边竖排的概率数字，不用操作。

### 无限时空点 / 挪移
自动的。花掉时空点或挪移后会自动补回 10。

### 星座可刷新
打开星座界面（局内点星座按钮），会看到多出来的**刷新**按钮。点它就重掷。

### 开局专长三选一
**开局后等 6 秒**，会自动弹出专长三选一面板，前两个是你当前指挥官的专属专长。

> 如果专属专长还没解锁，那就不出现，这是游戏本身的设计。
> 想手动再弹一次的话，按 **Z**。

### 设置面板开关
游戏自己的设置界面里会多出这几行，点一下就能开关对应功能，不用改文件。

## 想改配置？

配置文件在 `BepInEx\config\` 下面，按插件分文件：

| 文件 | 管什么 |
|---|---|
| `dicevaders.shopinfo.cfg` | 概率面板的位置、字号 |
| `dicevaders.resourcebuttons.cfg` | 补多少、补哪几种 |
| `dicevaders.constellationtool.cfg` | 刷新按钮位置、重掷上限 |
| `dicevaders.extrareward.cfg` | 开局专长面板的延迟、热键 |
| `dicevaders.qol.cfg` | 要拦掉哪些难度机制 |

用记事本打开改就行，改完重启游戏生效。

## 常见问题

**Q：游戏启动就崩 / 卡住不动**
A：八成是内存不够。关掉浏览器、聊天软件再试，腾出 2~3 GB 空闲内存。这游戏本身就挺吃内存。

**Q：第一次启动特别慢**
A：正常。BepInEx 要从游戏的 `GameAssembly.dll` 生成桥接程序集，1~3 分钟。之后就好了。

**Q：设置界面没看到「★ Mod：…」那几行**
A：进设置界面等一下（有刷新逻辑），或者重启游戏。还是没有的话把 `BepInEx\LogOutput.log` 发出来看看。

**Q：想装别的 Mod 会不会冲突**
A：用的是 BepInEx + Harmony，正常不冲突。但如果是同样改「幕奖励面板」或「星座界面」的 Mod，可能会打架。

**Q：怎么彻底卸载**
A：删掉 `BepInEx/plugins/DiceVaders.*.dll` 就行，其它文件留着不影响游戏原版运行。想彻底干净就把 `BepInEx\`、`dotnet\`、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` 一起删掉。
